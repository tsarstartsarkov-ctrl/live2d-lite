# Live2D Lite — APK

Простой анимированный аватар со своим 2D-скелетом (упрощённый Live2D):
слежение головы и взгляда за пальцем, моргание, дыхание, пружинная физика,
режим постановки позы перетаскиванием суставов, экспорт/импорт позы в JSON,
загрузка своего PNG-спрайта на кость головы.

## Способ 1. Сборка APK в облаке (без установки чего-либо)

1. Создай репозиторий на GitHub и загрузи в него содержимое этой папки
   (через веб-интерфейс: Add file → Upload files).
2. Открой вкладку **Actions** → запусти workflow **Build APK** (кнопка Run workflow).
3. Через ~3–5 минут в том же workflow, в разделе **Artifacts**,
   скачай `live2d-lite-debug-apk` — внутри готовый `app-debug.apk`.
4. Скопируй APK на телефон, установи (разреши установку из неизвестных источников).

## Способ 2. Android Studio

1. Установи [Android Studio](https://developer.android.com/studio).
2. File → Open → выбери эту папку. Дождись синхронизации Gradle.
3. Build → Build APK(s). APK будет в `app/build/outputs/apk/debug/`.

## Запуск без APK

Открой `live2d_lite_pro.html` в браузере телефона (можно «Добавить на главный экран»).

## Структура скелета

    root (таз)
    ├── torso (корпус)
    │   ├── head (голова)
    │   │   ├── eyeL / eyeR (глаза — зрачки следят за касанием)
    │   ├── armL / armR (руки, ограничители ±75° от покоя)
    ├── legL / legR (ноги)

Кости задаются в `app/src/main/assets/www/index.html` в объекте `bones`:
`p` — родитель, `ox/oy` — смещение, `a` — угол покоя.
